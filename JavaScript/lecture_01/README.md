### ECMAScript
ECMAScript (ES) is the standardized specification for scripting languages, most notably JavaScript. It provides the foundation for JavaScript, but JavaScript itself includes additional features not defined in the ECMAScript standard, which are added by the environment in which it runs, like a web browser or server. ECMAScript is maintained by the **[TC39 committee](https://tc39.es/)** at **[Ecma International](https://ecma-international.org/)**, and its versions are named by the year of their release, such as ECMAScript 2015 (ES2015). 


### Chrome V8 Engine
The V8 engine in Chrome is Google's open-source JavaScript and WebAssembly engine that compiles code to fast machine code for execution, allowing websites to run quickly. Named after a powerful car engine for its high performance, V8 is written in C++ and uses components like the **[Ignition interpreter](https://v8.dev/blog/ignition-interpreter)** and **[TurboFan compiler](https://v8.dev/docs/turbofan)** to optimize and execute JavaScript code. It also handles **[memory management](https://v8.dev/blog/optimizing-v8-memory)**, including **[garbage collection](https://v8.dev/blog/trash-talk)**, and enables features like **[sandboxing](https://v8.dev/blog/sandbox)** for security.

### What is Interpreted Language ?

    An interpreted language executes source code line-by-line at runtime using an interpreter, a separate program that translates the code into machine code on the fly without a prior compilation step. This makes for quick development and greater portability, as the same code can run on any system with the appropriate interpreter installed, though this process can be slower to execute than compiled code. Popular interpreted languages include Python, JavaScript, and Ruby.

### What is Compiled Language ?

    A compiled language is a programming language where the entire source code is translated into machine-readable machine code by a compiler before the program is run, resulting in a faster and more efficient executable file. This "build" step happens once, and the resulting program can be run independently on a target machine without the need for the compiler or additional software, although this process requires a rebuild whenever the source code changes.

### Difference between interpreted and compiled language.

    Is Python Compiled or Interpreted? Understanding Python's ...The primary difference is how code is executed: compiled languages are fully translated into machine code by a compiler before execution, resulting in faster runtime performance but a longer development cycle. Interpreted languages are translated and executed line-by-line at runtime by an interpreter, allowing for rapid development and execution but generally slower performance.

### Is JavaScript Interpreted or Compiled ?

    JavaScript is traditionally categorized as an interpreted language. This means that, historically, JavaScript engines would read and execute the code line by line at runtime, without a prior compilation step into machine-readable bytecode.
    However, modern JavaScript engines, such as V8 in Google Chrome and Node.js, employ Just-In-Time (JIT) compilation. This means that while JavaScript is still initially interpreted, frequently executed code segments are identified and then compiled into optimized machine code during runtime to improve performance. This makes the execution of JavaScript a hybrid process, combining aspects of both interpretation and compilation.
